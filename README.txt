CERCA YA - PROTOTIPO WEB

Archivos:
- index.html: pantalla principal
- styles.css: diseño
- app.js: búsqueda, filtros y formulario de demostración
- manifest.json y sw.js: configuración básica PWA

PUBLICACIÓN:
Sube todos estos archivos a la raíz de un repositorio GitHub y activa Settings > Pages > Deploy from a branch > main > /(root).

IMPORTANTE:
Este prototipo es una demostración. No tiene cuentas, base de datos compartida, chat real, moderación ni anuncios sincronizados. Las publicaciones agregadas en el formulario solo aparecen en la vista del dispositivo mientras está abierta.
